# Contributing

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## Contribution Guidelines

1. Fork the repository.
2. Create a new branch for your change.
3. Make your updates with clear, focused commits.
4. Test your changes before submitting them.
5. Open a pull request with a short description of what changed.

## Reporting Issues

When reporting a bug, include the steps to reproduce it, the expected result, and the actual result.

## Documentation Improvements

Documentation updates are encouraged, especially changes that make the simple interest calculator easier to understand or use.
